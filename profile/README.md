## 🛠️ Open-Source Developer Tools & Datasets

We build lightweight, zero-dependency tools to automate technical distribution:

### 1. [`md-to-thread`](https://github.com/eco-null/md-to-thread)
*Convert Markdown and articles into optimized X threads, LinkedIn carousels, and Threads drafts.*
```bash
npx md-to-thread README.md --limit 280 --format thread
```

### 2. [`social-text-styler`](https://github.com/eco-null/social-text-styler)
*Zero-dependency Unicode text formatter for LinkedIn and X: bold, italic, monospace, strikethrough, and script.*
```bash
npx social-text-styler "Product Announcement" --style bold
```

### 3. [`awesome-tech-hooks`](https://github.com/eco-null/awesome-tech-hooks)
*Curated dataset and CLI of 500+ viral hooks and opening frameworks for developers and founders.*
```bash
npx awesome-tech-hooks --random
```
